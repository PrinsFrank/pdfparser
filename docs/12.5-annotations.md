# Annotations (12.5)

An annotation associates an object such as a note, link or rich media with a location on a page, or provides a way to interact with the user by means of the mouse and keyboard.

## Links

If an annotation is of type link, `isLink` will return true. In that case, the link location can be retrieved using the `getLinkLocation` method;

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Annotation $annotation */
$isLink = $annotation->isLink();
$linkLocation = $annotation->getLinkLocation();
```

## Rectangle

To retrieve the rectangle for an annotation, you can use the `getRect` method.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Annotation $annotation */
$rectangle = $annotation->getRect();
```

## Field name/values

In case of annotations of type field, there are several methods available to retrieve the field name, alternative field name, the mapping name and the field value if filled in:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Annotation $annotation */
$partialFieldName = $annotation->getPartialFieldName();
$alternativeFieldName = $annotation->getAlternativeFieldName();
$mappingName = $annotation->getMappingName();
$value = $annotation->getValue();
```
