# Document catalog (7.7)

The root of the document objects` hierarchy is the catalog dictionary. It can be retrieved from the document:

```php
/** @var \PrinsFrank\PdfParser\Document\Document $document */
$document->getCatalog();
```

## Pages root

The document catalog provides access to the pages root with the `getPagesRoot` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Catalog $catalog */
$pagesRoot = $catalog->getPagesRoot();
```

[See the documentation on Page tree nodes](7.7.3.2-page-tree-nodes.md) for its documentation

## Interactive form

The interactive form (or AcroForm), can be accessed from the document catalog with the `getInteractiveForm` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Catalog $catalog */
$interactiveForm = $catalog->getInteractiveForm();
```

For methods on the [Interactive form, see its documentation.](./12.7-interactive-forms.md)

## File Specifications

To access all the file specifications for a document, use the `getFileSpecifications` method on the document catalog:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Catalog $catalog */
$fileSpecifications = $catalog->getFileSpecifications();
```

For more information about [file specification dictionaries, see the documentation on it.](7.11.3-file-specifications.md)
