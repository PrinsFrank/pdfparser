# Interactive forms (12.7)

Interactive forms, also called AcroForms, are a way to collect information interactively from the user.

## Fields

Fields can be retrieved by calling the `getFields` method.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\InteractiveForm $form */
$fields = $form->getFields();
```

See the [documentation on annotations to find out more about field annotations](./12.5-annotations.md)
