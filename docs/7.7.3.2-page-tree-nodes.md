# Page tree nodes (7.7.3.2)

The pages of a document are accessed through the Page tree. It defines the ordering of pages in the document.

## Page items

A list of pages can be retrieved by calling the `getPageItems` method on the `Pages` dictionary:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Pages $pages */
$pageItems = $pages->getPageItems();
```

See the documentation on [Page objects for available methods](./7.7.3.3-page-objects.md)

## Resource dictionary

To access the resource dictionary for a Pages dictionary, the method `getResourceDictionary` is available:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Pages $pages */
$resourceDictionary = $pages->getResourceDictionary();
```

## Media box

To retrieve the media box for a Pages dictionary, use the `getMediaBox` method. It returns either a rectangle or null:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Pages $pages */
$mediaBox = $pages->getMediaBox();
```

## Crop box

To retrieve the crop box for Pages, use the `getCropBox` method. It returns either a rectangle or null:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Pages $pages */
$cropBox = $pages->getCropBox();
```
