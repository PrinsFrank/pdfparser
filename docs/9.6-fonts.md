# Fonts (9.6)

## Base font

To retrieve the base font, use the `getBaseFont` method.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$baseFont = $font->getBaseFont();
```

## Encoding dictionary

To retrieve the encoding dictionary, use the `getEncodingDictionary` method.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$encodingDictionary = $font->getEncodingDictionary();
```

## Encoding

To retrieve the encoding for a font, use the `getEncoding` method. This value is cached after initial retrieval.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$encoding = $font->getEncoding();
```

## Differences

To retrieve the differences for a font, use the `getDifferences` method. After initial retrieval this value is cached.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$differences = $font->getDifferences();
```

## To Unicode CMap

To retrieve the toUnicodeCMap for a font, use the `getToUnicodeCMap` method. After initial retrieval, this value is cached.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$toUnicodeCMap = $font->getToUnicodeCMap();
```

## Descendant fonts

To retrieve the descendant fonts for a font, use the `getDescendantFonts` method. The descendant fonts are cached after initial retrieval.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$descendantFonts = $font->getDescendantFonts();
```

To retrieve the FontWidths or CIDFontWidths for a Font, use the `getWidths` method. After initial retrieval this value is cached.

/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */

## Font descriptor

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */

```

## Bold / Italic

There are two methods available to check if a certain font is bold/italic. This is based on if the base font contains any of the bold/heavy/black or italic/oblique/slanted words respectively.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Font $font */
$bold = $font->isBold();
$italic = $font->isItalic();
```
