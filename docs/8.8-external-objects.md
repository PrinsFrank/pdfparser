# External Objects (8.8)

An external object is a graphics object whose contents are defined by a self-contained stream, separate from the content stream in which it is used. There are two types of external objects, images and forms.

These can be retrieved on a page-by-page basis using `$page->getXObjects()`. If you are only interested in images, you can retrieve all image XObjects by calling `$page->getImages()`.

## XObject types

The type of external object can be retrieved by using the `getSubType` method. If you need to know if an xObject is an image or form, you can also use the `isImage` and `isForm` methods:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\XObject $xObject */
$isForm = $xObject->isForm();
$isForm = $xObject->isImage();
```

## Width

To retrieve the object width, use the `getWidth` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\XObject $xObject */
$width = $xObject->getWidth();
```
