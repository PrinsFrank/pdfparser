# Page objects (7.7.3.3)

Page objects are leaf nodes in the Page tree that represent pages.

## Positioned text elements

To retrieve all the text elements on a page including their absolute position, you can do so with the `getPositionedTextElements` method.
Please note that these are returned in the order they appear in the Content Stream. If you just want to extract the text/markdown in reading order, use `getText` or `getMarkdown` instead.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$positionedTextElements = $page->getPositionedTextElements();
```

## Text retrieval

To retrieve the text on a page, you can use the `getText` method;

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$text = $page->getText();
```

## Markdown retrieval

To retrieve a markdown representation of the content on a page, use the `getMarkdown` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$markdown = $page->getMarkdown();
```

## Content stream

If you need access to the parsed content stream, you can use the `getContentStream` method. This will return a ContentStream object or null.
Within the content stream there is a combination of text Objects and ContentStreamCommands. TextObjects contain ContentStreamCommands themselves as well.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$contentStream = $page->getContentStream();
```

## Resource dictionary

To retrieve the Resource dictionary for a Page, you can use the `getResourceDictionary` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$resourceDictionary = $page->getResourceDictionary();
```

## XObjects

To retrieve the XObjects related to a page, use the `getXObjects` method.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$xObjects = $page->getXObjects();
```

For information about the methods available on the [External object dictionaries, see the documentation about them.](./8.8-external-objects.md)

## Images

To retrieve all images for a page, the `getImages` method is available. It returns all XObjects that are images.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$images = $page->getImages();
```

For information about the methods available on the [External object dictionaries, see the documentation about them.](./8.8-external-objects.md)

## Fonts

To retrieve a specific Font by name for a page, use the `getFont` method with a NameObjectStringValue for the specific font you want to retrieve:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$font = $page->getFont(new \PrinsFrank\PdfParser\Document\Dictionary\DictionaryValue\TextString\NameObjectStringValue('FontName'));
```

For information about the methods available on the [Font dictionaries, see the documentation about them.](./9.6-fonts.md)

## File specifications

To retrieve file specification for a page, use the `getFileSpecifications` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$fileSpecifications = $page->getFileSpecifications();
```

For information about the methods available on the [File specification dictionaries, see the documentation about them.](7.11.3-file-specifications.md)

## Media box

To retrieve the mediaBox for a page, use the `getMediaBox` method:

If the page itself doesn't contain a mediaBox, the parent's mediaBox will be returned as this is an inherited property.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$mediaBox = $page->getMediaBox();
```

## Crop box

To retrieve the cropBox for a page, use the `getCropBox` method:

If the page itself doesn't contain a cropBox, the parent's cropBox will be returned as this is an inherited property.

If neither the current dictionary nor the parent dictionary contain a cropBox value, this method will return the value for the mediaBox.

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$cropBox = $page->getCropBox();
```

## Annotations

To retrieve the annotations for a page, use the `getAnnotations` method:

```php
/** @var \PrinsFrank\PdfParser\Document\Dictionary\Decorator\Page $page */
$annotations = $page->getAnnotations();
```

For information about the methods available on the [Annotation dictionaries, see the documentation about them.](./12.5-annotations.md)
