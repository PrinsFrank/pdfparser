# Encryption (7.6)

PDFs can be encrypted. These can be secured by a user or owner password. To read these PDFs, you need to pass a user and/or owner password when parsing the file. All of the `parse` methods accept a second/third `$security` parameter, so `parseFile` or `parseString` also accept a StandardSecurity instance.

```php
/** @var string $path */
$document = (new \PrinsFrank\PdfParser\PdfParser())
    ->parseFile($path, security: new \PrinsFrank\PdfParser\Document\Security\StandardSecurity('userPassword'));
```

```php
/** @var string $pdfContent */
$document = (new \PrinsFrank\PdfParser\PdfParser())
    ->parseString($pdfContent, security: new \PrinsFrank\PdfParser\Document\Security\StandardSecurity(null, 'ownerPassword'));
```

```php
/** @var InMemoryStream $stream */
$document = (new \PrinsFrank\PdfParser\PdfParser())
    ->parse($stream, security: new \PrinsFrank\PdfParser\Document\Security\StandardSecurity('userPassword', 'ownerPassword'));
```

## Encrypt dictionary

When a document is encrypted, it will have an Encrypt dictionary. You will never have to manually interact with that Encrypt dictionary however. Decryption is done transparently when a correct user password or owner password is supplied. As such, the Encrypt dictionary decorator is not part of the public API.
